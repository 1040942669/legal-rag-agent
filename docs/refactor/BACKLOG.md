# 改造后续备选需求

这些尚未获准进入当前里程碑。只有具体问题/失败样例证明必要，并明确范围后才实施。

| 候选 | 触发条件 | 最小实验 | 本轮默认 |
|---|---|---|---|
| 法律版本更新影响分析 | 已有两个可核实文本快照 | diff → 受影响 embedding/case → 回归 → 人工审核 → 快照切换 | 不做，优先后续方向 |
| 独立重排器 | 高召回但 top-k 顺序差 | 固定召回与生成，仅比较重排 | 不自动加模型 |
| Qdrant/Milvus 第二适配器 | 岗位或实际过滤/扩展需求明确 | 同一向量与过滤条件比较 | 不同时接入多个库 |
| 长期记忆 | 跨 session 的明确用户需求 | 有权限、保留/删除策略的小范围设计 | 不把所有对话向量化 |
| 语义答案缓存 | 已证明精确缓存不足且风险可控 | 跨版本/权限负例测试先行 | 关闭 |
| 通用多 Agent/沙箱 | 单 Agent 无法解决且有数据证明 | 独立项目范围评审 | 不做 |
