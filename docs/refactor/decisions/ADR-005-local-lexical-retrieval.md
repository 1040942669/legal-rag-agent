# ADR-005：有界本地词汇检索候选与证据充分性边界

状态：accepted；有界机制保持显式 opt-in，固定对比不支持升级默认
日期：2026-10-04
影响里程碑和版本：已发布 M6 之后的独立本地质量修复，不启动 M7，不产生新 Tag / Release

## 背景

真实修复轮 `live_smoke_20261003_repair` 在第五题停止。网购退货问题没有命中目标条文，草稿的 `insufficient_evidence` 与固定评测预期 `evidence_answer` 不一致；最终受限响应通过检查不能掩盖草稿失败。前四题正文引用合同检查通过，也不证明所有法律结论正确。该历史与两轮付费账本保留，不改写为本次候选的质量证据。

当前直接 BM25 路径使用原始问题，没有启用 adaptive 或模型改写。旧分词器先汇集整段汉字再生成相邻二元词，可能把标点、英文或数字两侧不相邻的汉字连成不存在的词。口语购买和退货表达还可能缺少法律文本中的常用词汇，而“质量问题”等字词让其他领域条文获得很高的 BM25 分数。高分、法名存在和来源编号有效都不等于证据在语义上支持回答。

本次只处理可离线复现的词汇检索与证据闸门问题。保持 article 切分、现有语料与固定题标、拒答和 verifier 合同、权限与快照边界。没有第三次付费复验、外部 embedding / Judge、服务部署或远端 Git 操作授权。

独立合成负例还暴露了旧证据检查的三个通用缺口：相关法名子串被视作同一法律，法名和条号可以从不同法律的结果集合拼接，非有限或类型无效的高分未明确失败关闭。这些属于证据所有权和输入有效性，而不是词汇排名策略；本次收紧这些合同，不因此把高分判成语义支持。

## 可选方案

| 方案 | 解决什么 | 引入什么成本 | 不适用边界 |
|---|---|---|---|
| 保留 `legacy-v1`，只记录失败 | 不改变兼容行为；保留历史可复现性 | 已知口语检索与跨边界二元词问题继续存在 | 不能据此声称网购题已经修复或旧证据充分性等于语义支持 |
| 启用宽泛 adaptive、推断法名或提高法名 boost | 扩展检索概念或扩大目标领域分数 | 增加规则或模型调用、误路由和维护成本；改变既有默认路径 | 没有当前固定 A/B 证据；不得从 gold 法名、条号或答案反推运行时规则 |
| 显式 `local-lexical-v2` 候选及独立证据负例 | 修正连续词边界；加入少量可解释的购买词汇；限制重复查询词权重 | 文档统计需重建；可能发生其他题排名回退；增加规则与版本合同 | 只覆盖明确实物购买语句，不是通用语义理解器、法律资格判断或默认最优策略证明 |

## 决定

接受第三种机制作为可解释、可关闭的显式候选，保留 `legacy-v1` 为默认排名和回退路径。唯一最终固定实验 `offline_lexical_ab_20261004_first` 的净命中增加伴随两题回退，配对置信区间跨零，且没有新 holdout 或真实生成验证，不能据此推广默认。accepted 表示接受这一工程边界与 opt-in 方案，不表示整体法律质量或发布门禁通过。

候选合同为：

- 汉字二元词只在连续汉字片段内生成，不跨标点、英文、数字或换行；ASCII、显式书名号法名和条号特征继续保留。
- 原始 query 仍进入分词、法名/条号提取、风险判断和上层拒答。规范词汇只追加检索特征，不重写问题、消除否定或生成法律结论。
- 明确实物购买语句可追加 `购买`、`商品`；同一购买短语明确网络渠道时可追加 `网络`；明示退货意图可追加 `退货`。扩展只加入完整词一次，不把扩展词再拆成泛单字加分。
- 否定购买或渠道、平台名称、金融/不动产语境、退税/退学、买通/收买、明显多主题句和缺少实物对象的购买保持不扩展。未覆盖表达保留原始 BM25 特征，不把规则未命中解释成法律上不可退货。
- 候选去重查询特征，但保留文档 term frequency。不能为了某个 case ID、gold 法名、条号、期限、关键词或期待模式编写运行时分支；例如不得注入问题中未明示的退货期限或资格结论。
- 证据闸门的法名匹配只允许书名号、空白及国家前缀的精确别名归一化，不把实施细则或其他相关法律当作同一法律。显式且无歧义的单法条号请求要求同一条 typed provenance 关联该法名与条号；无 typed provenance 的多法混合 Chunk 不能靠字段集合证明归属。多个显式法律的条号对应仍不猜测，保留局限。所有结果分数必须是非 bool 的有限实数，否则失败关闭。这三项收紧适用于两个 profile。
- 商品退货必要条件仅用于纯 BM25、结果 trace 全部为 `local-lexical-v2` 且问题确实产生 `退货` 扩展的路径：至少一个同一结果正文含 `退货` 及 `商品`、`货物`、`物品`之一，否则程序化进入资料不足，不调用生成。它不推断是否符合退货资格，不用于 dense/混合路径，也不因必要词存在把 `semantic_support_status` 自动改为 supported。结构、行为、语义检查继续分层；不能放松 verifier 让模型自报资料不足覆盖当前预期模式。

词汇特征仅参与已经取得的 Chunk 评分。不改 `Chunk.text`、法名、条号、metadata、来源、payload fingerprint；不扩大 PostgreSQL 允许的 scope/profile/snapshot，不增加越权语料加载，保留 `BoundaryBoundRetriever` 的结果复核。

`legacy-v1` 的 query/document text version 维持旧身份；候选分别使用 `bm25-query-local-lexical-v2` 和 `bm25-document-contiguous-v2`，trace 记录 profile 与扩展词。CLI/配置、生效 retriever 与 experiment manifest 必须描述同一实际策略。词汇或证据实现改动进入相应 stage implementation fingerprint，检索缓存不得跨版本复用；生成和验证缓存还需要包含实际证据输入身份。旧付费 manifest、summary、ledger 和失败报告不为新版本改写。

## 验证与代价

测试/实验：唯一最终 Run ID 为 `offline_lexical_ab_20261004_first`，执行于 `2026-10-04T08:17:45Z` 至 `08:20:57Z`，child / shell exit 均为 0。完整固定 v3 题集为 120 题，其中 108 条检索 gold 样例、12 条拒答样例。两臂使用相同 19,050 个 article Chunk、top-5、BM25 参数及 0.5 的废止法律乘数。每题创建独立 assistant，按两个 profile 的 A/B 与 B/A 先后顺序各执行两次，逐题结果及分数一致；这不是整题集逆序实验。拒答题在检索前验证路由，不混入检索命中分母。108 条均形成有效配对，执行失败、顺序不一致和提供商调用均为零；输入、数据集和代码冻结身份检查均为 true。不得与不同口径的旧汇总值直接比较。

| 同一最终 run 的指标 | `legacy-v1` | `local-lexical-v2` |
|---|---:|---:|
| Hit@3，分母 108 | 0.648148 | 0.675926 |
| Hit@5，分母 108 | 76/108，0.703704 | 78/108，0.722222 |
| MRR，分母 108 | 0.610184 | 0.624227 |
| target coverage，分母 108 | 0.660494 | 0.679012 |
| 检索前拒答路由，分母 12 | 12/12 | 12/12 |

Hit@5 转换为 4 题改善、2 题回退、74 题维持命中、28 题维持未命中；配对增量为 0.018519，bootstrap 95% CI 为 `[-0.0278, 0.0648]`。回退题 `v3_scene_work_injury` 与 `v3_adaptive_multi_return_info` 都从第 5 名命中变为 top-5 未命中，且其证据启发式仍为 sufficient，不能隐藏。启发式 sufficient 但没有 gold 命中的条数由 30 变为 28，这不是语义支持数量。

另外 8 条合成、未经权威法律复核的 gold 改写命中从 7/8 变为 8/8；8 条无 gold 的词汇负例均无意外激活。这些是工程挑战集，不是独立法律 holdout，不能合并成 116 条法律质量样本。重叠的 30 条 generation subset 仅做 retrieval-only 分层，不生成回答，也不构成独立验证。

合成负例覆盖跨标点/ASCII/数字二元词、查询重复与文档频率、原始显式法名条号、否定网络渠道、未购买、平台名称、非实物购买、多主题以及高分但不相关的证据。独立专项复测覆盖词汇候选、证据安全、配对评测、权限绑定检索与 M2 stage cache 方向性，于 `2026-10-04T08:23:48Z` 至 `08:23:51Z` 得到 exit 0、134 passed in 1.23s，JUnit 为本地 `.tmp/offline-lexical-independent-final.xml`。这不是累计 M2 或服务/发布门禁，完整门禁与未运行项以最终验收报告为准，不用旧 CI 冒充本次通过。

性能、成本、维护与兼容性影响：无需新依赖、新模型、数据库 migration 或外部调用。外部模型调用成本为零不等于本地 CPU/内存耗用为零；分词改变会重建 BM25 文档统计并影响不同题目排名。完整实验耗时 191,551.246 ms。主集每臂的 240 个实际耗时样本包括准备、拒答路由、检索和证据检查，排除建立与评分；不只是 108 条纯 BM25 检索，也不是服务 P95。该本地运行 median/P95 为旧臂 329.408/724.151 ms、新臂 312.172/705.891 ms，不能据此作生产速度提升保证。保留可解释、有限词汇范围，避免无界追补法律知识规则。

无法验证的部分：retrieval-only A/B 不生成真实回答，不能证明提示修复后的整轮 Smoke 通过、法律准确率提高、引用蕴含、现行法律覆盖或生产性能。合成 fake 仅证明工程合同；第三次真实模型、人工法律评审、M6 broker/数据库故障复验与远端 CI 均不在本次验证范围。

## 回退和替换条件

固定题集出现不可接受回退、负向边界被破坏、manifest 与生效策略不一致、缓存错误复用、权限/来源改变或 mandatory 门禁失败时，不推广默认。显式选择 `legacy-v1` 回退排名策略，保留新旧实验、失败和代码版本，不删账本、重写题标、改 verifier 迎合结果或移动已发布 Tag。

旧证据闸门的不充分语义保证不因排名回退而被宣称安全。若日后发现本地词汇范围不足，先形成新的固定失败集和权限/费用范围，再比较其他检索或评审方案，不在本次自动启用 adaptive、其他模型或更大规模评测。
