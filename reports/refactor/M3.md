## 数据身份与导入语义

模块 A 将“同一语料”和“同一向量产物”拆开：

- `corpus_hash` 包含 snapshot、法律版本、法条、chunk、ordered relations 和 source manifest，不包含 embedding profile。
- `profile_id` 绑定 provider、model、revision、维度、归一化和 query/document recipe。
- `bundle_hash` 绑定 corpus hash、profile 和每个向量的 float32 字节 hash。
- 同一 snapshot 可为多个 profile 保存 embedding；同一 snapshot/profile 只能有一个完全一致的 validated import receipt。

导入顺序在一个事务内完成。所有稳定 ID 都按实际字段验证；embedding 同时验证声明 hash、维度和数据库回读后的向量字节 hash。完全相同的重复导入返回 idempotent；任何不一致返回 conflict；任一后段异常使本次新增行全部回滚。

## 对抗审查结果

模块 A 在提交前针对以下风险做了修正并复验：

- 集成测试从共享数据库改为每次 invocation 创建/删除唯一数据库。
- rollback 用例改为先插入快照、再制造后段 embedding 冲突，证明整事务回滚而不是只测前置校验。
- 测试彼此不依赖执行顺序；并发 importer 有独立覆盖。
- 幂等验证不只比较 hash，会比较完整标量值、ordered relations、成员集合和实际向量。
- Alembic resources 加入 wheel package data；CI 构建 wheel 后实际检查资源。
- pgvector CI image 固定 tag 与 digest，避免浮动 service image。

当前没有模块 A 范围内的 P0/P1/P2 阻塞。尚未实现的 exact、filter、activation、ANN、upgrade 和 service restart 被保留为后续模块，不以限制说明代替实现。
